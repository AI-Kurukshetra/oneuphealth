# Health Platform

Healthcare interoperability platform scaffold built with Next.js 15, TypeScript, Tailwind CSS, and Supabase.

## Run

```bash
npm install
npm run dev
```

## Key Folders

- `app/` App Router pages, APIs, and server actions
- `components/` reusable UI
- `services/` domain workflows
- `repositories/` Supabase data access
- `lib/` auth, Supabase, FHIR, validators, utilities
- `types/` shared TypeScript contracts
- `database/` SQL migrations and seed notes
- `docs/` architecture and generation rules
